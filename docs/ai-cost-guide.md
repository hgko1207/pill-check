# AI 코딩 비용 관리 가이드

> 요금제 가격과 한도는 자주 바뀝니다. 금액은 이 문서에 적지 말고, 결정할 때 Anthropic 공식 요금 페이지에서 확인합니다.

## 1. 요금제 고르기

| 상황 | 검토할 방식 |
|---|---|
| 팀원 대부분이 매일 쓴다 | 팀 구독 요금제 (1인당 정액) |
| 몇 명만 가끔 쓴다 | 사용자별 개인 구독 또는 API 종량제 |
| 보안·감사 요구가 크다 | 엔터프라이즈 계약 (관리형 설정, 사용량 분석) |
| CI·자동화에서 쓴다 | API 키 종량제, 자동화 전용 키 분리 |

**우리 팀 결정**: {{요금제}} · 결정일 {{YYYY-MM-DD}} · 다음 재검토 {{YYYY-MM-DD}}

## 2. 사용량 확인

- 세션 비용: Claude Code에서 `/cost`
- 사용량 내역: `/usage`
- 플러그인·스킬이 차지하는 토큰: 터미널에서 `claude plugin details team-ai`
- 관리자 대시보드: {{조직 콘솔 주소 또는 담당자}}

## 3. 비용을 줄이는 습관

- 작업이 바뀌면 `/clear`로 새로 시작합니다. 긴 대화는 매 요청마다 비용이 늘어납니다.
- 큰 파일 전체를 붙여 넣지 말고 경로를 알려 줍니다.
- 쓰지 않는 플러그인·MCP 서버는 끕니다. 항상 켜진 것들도 토큰을 씁니다.
- 단순 작업에는 가벼운 모델이나 낮은 effort를 씁니다. ({{팀 기본 모델 규칙}})
